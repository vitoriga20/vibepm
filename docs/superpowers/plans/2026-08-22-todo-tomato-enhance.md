# 番茄钟 To-Do 增强·验收计划（业务视角）

日期：2026-08-22
插件：`vibepm-ts/packages/plugin-todo-timer`
状态：待开发（每项验收经真机验证后通过）

---

## 范围界定

- **本次做**：四象限（组织）、计划（长期目标/里程碑）、任务-专注耦合、数据复盘。
- **本次不做**：预估番茄数（用户拍板去掉）；声音/音效（已删除，保留删除状态）；生长动画任务化（保持现状）。
- 任务类型仅指现有「待办/进行中」任务；长期计划独立于四象限平级呈现。

> 说明：以下验收全部以「用户能直接感知的行为」描述，判据可人工真机验证，不含实现细节。

---

## 验收一：任务-专注耦合（核心闭环）

1. 开始专注时：当前待办里若已有「开始做」的任务，则该任务成为本次专注的绑定对象，无需再次选择。
2. 若没有「开始做」的任务，开始专注给出温和提示，引导先在待办里把某条设为「开始做」，但不强制打断专注。
3. 专注进行中：主导航时钟旁与右下角胶囊顶部都清晰显示「正在专注哪条任务」，任务变更时同步刷新。
4. 一次专注结束（无论跑满或中断）：只对绑定任务累计番茄，其它任务不受影响。
5. 完成反馈：专注结束时明确给出一条结果提示——本次番茄 +1、该任务累计番茄总数；此前预估番茄功能已去掉，故不再显示「预估偏差」。

## 验收二：四象限（组织）

1. 每条任务可标记「重要 / 紧急」两个维度，两两组合成 Q1(重要+紧急)、Q2(重要)、Q3(紧急)、Q4(都不)。
2. 任务卡片能一眼看出所属象限（卡片上有象限标识）。
3. 列表默认按象限排序：Q1 在最上，再依次 Q2、Q3、Q4；同象限内按创建时间新到旧。
4. 标记重要/紧急后列表顺序实时重排，无需刷新。

## 验收三：计划（长期目标/里程碑）

1. 提供「计划」的独立入口，与日常待办分开，用于承载长期目标/里程碑。
2. 一条计划可包含多段里程碑，里程碑可有时间先后（先后关系不影响并行执行待办）。
3. 计划/里程碑与四象限任务可双向关联：一个里程碑可挂若干待办；点击可跳转到对应待办。
4. 计划完成 / 里程碑达成有明确的状态标记，达成后可归档并回看。

## 验收四：数据复盘

1. 每张任务卡片能查看本任务累计专注番茄总数（从「开始做」起累计）。
2. 从「计划」视角能查看该计划下各待办的番茄累计，直观看出投入分布。
3. 提供简单汇总：四象限各自的任务数与番茄投入一览（本页内展示即可）。

## 体验约束（贯穿所有验收）

- 全程无新增声音/音效；生长动画保持现状，不因本次改动变化。
- 新旧数据兼容：老用户历史任务不丢、不报错。
- 任何一处开关/数值变化都实时生效，不要求刷新。
